# T.I-Tools---Support-Center
TI TOOLS é uma ferramenta em PowerShell para suporte técnico e manutenção de computadores Windows. Reúne recursos de limpeza, diagnóstico de rede, verificação de discos, reparação do sistema, recuperação de inicialização (BCD) e inventário de hardware, proporcionando mais agilidade e praticidade no atendimento técnico.
